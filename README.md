# qiick-website review assets

Viewport screenshots embedded in pull requests for
[LucaGiardi20/qiick-website](https://github.com/LucaGiardi20/qiick-website).
Public so that images render in PR bodies without GitHub authentication.

Captured with Playwright at 320 × 720, 768 × 900 and 1440 × 900,
`color-scheme: light`, reduced motion, fonts loaded and a 1.2 s settle delay.
